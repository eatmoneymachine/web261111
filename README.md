# web 261111 — 11주차 수업 실습 결과물

## 파일 구성
- `index.html`: 영화 보드 구조, 정렬 선택 상자, CSS/JS 연결
- `style.css`: 기존 보드 디자인과 반응형 레이아웃, 평점 강조 스타일
- `data.js`: 영화 6편의 데이터
- `app.js`: 포스터 주소 처리, 카드 생성, 정렬 기능

## 구현 내용
- HTML에 카드(article)를 직접 작성하지 않고 JavaScript로 생성
- 평점 8.0 이상인 영화의 배지를 빨간색으로 표시
- 영화 개수 표시
- 평점순 / 최신 개봉순 / 제목순 정렬
- 영화 데이터 배열에 6번째 영화 추가

## AI 사용 기록
요청: 첨부된 11주차 실습 안내 PDF와 기존 HTML/CSS/JavaScript 파일을 바탕으로 완성 파일 생성.
답변 요약: 기존 영화 보드 디자인을 유지하면서 카드 생성 및 정렬 코드를 구성하고, 6편 데이터와 개수 표시, 평점 강조 기능을 적용함.
